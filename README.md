# 💬 React Firebase Real-Time Chat App

A modern **real-time chat application** built with **React.js** and **Firebase**.

The application allows users to create accounts, log in, search for other users, start conversations, send real-time messages, share images, use emojis, and block/unblock users.

This project was built to practice building a complete real-time application with React, Firebase Authentication, Cloud Firestore, Firebase Storage, and Zustand.

---

## 🚀 Features

- 🔐 User authentication with Firebase
- 📝 Sign up with email and password
- 🔑 Login with email and password
- 👤 User profile management
- 🔎 Search for users
- 💬 Real-time messaging
- ⚡ Real-time chat updates using Firestore
- 🖼️ Send images in chat
- 😊 Emoji picker support
- 🔔 Toast notifications
- 📱 Responsive user interface
- 🚫 Block and unblock users
- 🔄 Automatic message scrolling
- 🗂️ Chat list management
- 🧠 Global state management with Zustand
- ☁️ Firebase Cloud Firestore database
- 📦 Firebase Storage for image uploads
